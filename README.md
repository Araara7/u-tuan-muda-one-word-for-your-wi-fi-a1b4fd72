My entry for the [One Word for Your Wi-Fi](https://make.fun/bounty/u-tuan-muda-one-word-for-your-wi-fi-a1b4fd72) competition on [make.fun](https://make.fun).

## The word

**Flaky** — my Wi-Fi drops whenever it feels like it. One word, instantly understood, and true to how home Wi-Fi actually behaves.

## How it works

`main.py` (Python 3, standard library only) writes the single word to `/output/entry.txt`. The entry is 5 characters, within the gate's 1–20 character limit, and deterministic — every run writes the same bytes.
